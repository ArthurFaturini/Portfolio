Laboratório Maker & Ideias

Um espaço dedicado a experimentações, arquitetura de sistemas em planejamento, consertos do cotidiano e ideias(mirabolantes) que estão saindo do papel.

// CRIAÇÕES & RASCUNHOS

Assistente Virtual com IA Local

[IA Local]

Arquitetura conceitual de um assistente pessoal inteligente projetado para ser executado 100% offline em hardware local. Elimina a dependência de APIs pagas em nuvem e o compartilhamento de dados com terceiros, integrando modelos de linguagem locais (LLMs) ao controle de rotinas do sistema operacional.

Status: Em planejamento [+ ver detalhes]

ML para Avaliação de Teoria Musical

[Machine Learning]

Conceito de modelo de aprendizado de máquina inspirado em literatura científica sobre a evolução e simplificação da música moderna. O algoritmo processa parâmetros de teoria musical e extração de características de áudio. Visando avaliar objetivamente a complexidade de composições atuais em comparação a padrões clássicos e históricos.

Status: Em planejamento [+ ver detalhes]

Facilitador de Servidores de Jogos

[Redes / Utilidade]

Ferramenta desktop voltada a simplificar a criação e exposição de servidores de jogos multiplayer. Abstrai a complexidade de terminal do Playit.gg e a instalação manual de dependências, oferecendo uma interface gráfica intuitiva para que o usuário médio suba servidores locais e túneis de rede (CGNAT) com poucos cliques.

Status: Em planejamento [+ ver detalhes]

Soundpad Desktop

[Full Stack / App Desktop]

Aplicação desktop de áudio desenvolvida com arquitetura híbrida (Python e Web). Foca na usabilidade e simplicidade visual para criadores de conteúdo e uso em chamadas no Discord. Gerenciamento simplificado de biblioteca de sons e baixíssima curva de aprendizado.

Status: Em desenvolvimento [+ ver detalhes]

Setup de Streaming Remoto

[Redes / Gambiarra Funcional]

Infraestrutura de streaming de alta performance e baixa latência projetada para jogos, contornando limitações de hardware local. Combina o Tailscale para criar uma rede Mesh privada via tunelamento seguro com o ecossistema Sunshine/Moonlight.

Status: Concluído / Em uso [+ ver detalhes]

Mini-Servidor J8

[Reciclagem Tech / Home Lab]

Servidor de monitoramento e controle remoto hospedado em hardware reaproveitado (Samsung J8). Integrado a um bot no Telegram em Python para comandos de controle remoto, gestão de status do PC principal, Wake-on-LAN e acesso via SSH para manutenção emergencial.

Status: Reavaliando projeto [+ ver detalhes]

Aplicativo de Finanças Pessoal

[Redes / Fintech]

Aplicação financeira multi-usuário containerizada no Docker e restrita à rede privada via Tailscale. Projetada para gestão individual e compartilhada de contas de casal com segurança e sem dependência de nuvem pública.

Automação de Irrigação IoT

Projeto conceitual utilizando microcontroladores e sensores de umidade do solo para prototipagem de uma rede doméstica de controle hídrico automatizado.

STATUS [Em Planejamento / Rascunho]
CATEGORIA Hardware / IoT / Automação
STACK TEÓRICA ESP32, MicroPython, MQTT, C++

// 01. A DOR (O PROBLEMA)

A manutenção manual de plantas em períodos de ausência prolongada ou rotinas intensas de desenvolvimento gera perdas recorrentes por falhas humanas na frequência de rega. Sistemas comerciais fechados existentes no mercado carecem de flexibilidade para integração com automações customizadas via rede local ou dashboards próprios, motivando a necessidade de prototipar uma solução modular, econômica e transparente de ponta a ponta.

// 03. APRENDIZADOS & PRÓXIMOS PASSOS

Nesta fase de concepção, o principal desafio identificado diz respeito ao isolamento adequado de umidade nos conectores e ao consumo energético otimizado do ESP32 em modo deep-sleep. Como próximos passos, planejo realizar testes de bancada utilizando fontes de alimentação chaveadas isoladas e escrever o primeiro script de validação de leitura analógica do sensor de solo.
